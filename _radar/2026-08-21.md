## 实测数据（`prose-and-register.md` 两处指针的目标）

逐类判读：

| 类别 | 数量 | 真信号还是噪音 |

| `quote`：ASCII 引号内为纯英文 | **275 处** | ❌ 假阳性 —— 英文短语用 ASCII 引号是对的 |
| `casing` 27 条 | 逐条看过 | ❌ **全部**是裸标识符：`settings.json` / `CMakePresets.json` / `.mcp.json` / `session id` / `node id` / `vertex id` / 域名 `ai.rundatarun`。一条真问题都没有 |

+ 一条副产品判据（**术语大小写检查器的假阳性清单 = 裸标识符清单**，跑一遍读误报比人眼扫快）。

### 👁 观察（有真信号，但本轮**故意不动**）

- **842 处 ASCII 引号包中文 + 88 个中文弯引号**。统一它是跨 121 文件的机械改写：收益是读起来一致，代价是污染 `git blame`
  且跟进行中的工作冲突。**先只在新写的内容里守住 `「」`**，不做历史清洗；真要清时先配一条会红的判据（正则：ASCII 引号内含 CJK），再动。
- **`对齐 / 闭环 / 联动 / 协同` 共 38 处存量**。规则已落，存量未改——同上，等各文件下次实质修改时顺手改，不做一次性 sweep。

### 📥 值得后续单独评（本轮读了原文，但超出用户批准的 A/B 范围，未落地）

[`yikeke/zh-style-guide`](https://github.com/yikeke/zh-style-guide)（MIT，1030 star，最后更新 2025-01-06）比 Fenng 那份**更全，且补的正是本仓库的空白**——
Fenng 几乎不碰文档结构，而这份的第 3、4 章就是结构与内容元素。从 `.rst` 原文摘出的、对本仓库真有用的条目：

- **标题**：最多四级、**禁止跳级**、下级标题禁止重复上级、避免孤立编号（同级只有一个）、**项目列表下禁止嵌套任何级别的标题**、
  描述操作任务用「动词 + 主题词」而非名词词组。→ 本仓库 `documentation.md` 完全没有标题规则，而这几条都可机械检查。
- **列表**：≥3 项才用纵向列表（少于 3 项且无需强调就写进句子）；**顺序不重要就不要用有序列表**；并列项句子结构相似、长度接近。
- **表格**：必须有表头；**不留空单元格**（填「无」或说明含义的符号）；不用「同上」；同类表格表头描述全文统一。
- **注意 / 说明块**：不超过 4 行；**不能包含表格和图**。→ 本仓库的 `>` callout 经常超长。
- **单位符号**：数值与单位空一个半角空格（`7 kg` / `53 MB`），**例外**：角度 / 摄氏度 / 百分号不空格（`60°` / `37°C` / `100%`）。
- **空白**：一律半角空格；中文与英文 / 数字之间空格，例外是句首省左侧、右邻标点省右侧；禁止连续 2 个以上半角空格 / 空行。
- **段落 / 句子**：段落 50–200 字（不超 250）、中心句放段首（= 本仓库「结论先于细节」）；句子不超 100 字、避免「一逗到底」。
  ⚠️ 后者本仓库违反得很厉害，但这是**风格取向**（高密度对 agent 读者未必是缺点），promote 前需要先想清是不是真要这条。
- 它自己推荐的工具链里有 **[Vale](https://github.com/errata-ai/vale)** —— 可配置 style 规则的散文 linter。**这是本轮最值得跟进的工具线索**：
  比 `autocorrect`（只管 CJK 留白 / 大小写 / 错字）灵活，可以把本仓库自己的规则写成可执行 style。

## 诚实边界

- **无对抗核验、无多票**。本轮所有断言的强度分两档：**实测**（linter 扫描结果、黑话计数、`repo_digest.py` 跑通、yikeke `.rst` 原文引用）
  与**判断**（哪些该吸收 / 哪些受众错位）。后者是单人一次判断，没有独立复核。
- 促成的 5 条**全部来自外部语料，不是本仓库踩坑挣来的** —— 按 `knowledge-promotion.md` 本该只留在雷达里。
  例外理由：其中「标识符加代码环境」这一条**有本仓库实测证据**（27 条误判），够得上「命中一次」；
  其余 4 条是**低风险文体约定**（写错了代价是读者算错数 / 多读一遍，不是系统故障），且用户当场逐档批准。
  ⇒ 定性为 **apply-and-refine**，不声称已验证。
- **它规范本身的证据强度**：全部是「应当如此」，没有一条写了「这条踩过几次 / 在哪验的 / 诚实边界」。这跟本仓库的证据纪律差一整层，
  引用它的内容时不要转述成「实测如此」。
