### 1. Model-visible ⟺ logged:模型可见输入与 session 日志的双向耦合不变量 `[confidence: high | 3 票核验]`
- **是什么**:dsh 把「任何进入 model request 的内容必须能从 session log 重建;新增一种模型可见输入就必须配套新增一种 session event」定为仓库级硬不变量,写进其 AGENTS.md。
- **为什么可能跟你相关**:对到 `guidelines/claude-code/` 的 harness hidden-contract 槽位与 `multi-session-coordination` 的 hook 注入面——本 corpus 有多处往 prompt 注入上下文的机制(UserPromptSubmit 注 inbox / git log、skill 常驻正文),但从未立过「注入内容必须可从日志重建」的可审计性规则。这是 enumerate-then-adjudicate 式「不可见失败变可见」思路在 harness 观测层的对应物,可平台中立化。
- **促成门槛**:读 dsh 源码确认该不变量的 enforcement 是纯 review 约定还是有机械检查;再实测 Claude Code——hook 注入的 context 在 transcript/session 文件里是否已可完整重建,列出缺口后才可落规则草稿。
- **来源**:https://github.com/deepseek-ai/deepseek-harness/blob/master/AGENTS.md ——"**Model-visible ⟺ logged**: anything that reaches a model request must be reconstructable from the session log; a new model-visible input requires a session event."

### 候选 #1 核验:成立,且促成价值上调

- **「从 log 重建」是生产路径本身,不是 replay 附件**:每个 step 的请求 messages 字面上就是 `session.deriveMessages()`(log surface 投影,`packages/core/agent-loop/src/agent.ts:340`);system/tools 每 step 现算但分发前全量落 `request/header` event("It is log-only; the latest snapshot reconstructs the request header")。
- **enforcement = 四层机械 + 一层 opt-in 运行时断言**:① 类型层——`SurfaceEventType` 闭合三元联合(`user/message`/`assistant/message`/`tool/result`),新的模型可见输入机械上只能以 log event 进入;② AST 扫描生成器 + CI `verify-persistence-catalog`(声明新 event 不再生成 catalog 就挂);③ `append` 现场校验 + 持久化读路径**拒识未知 event 类型**(防静默跳过导致错误重建);④ THEOREM 测试:每个请求用 fresh Session 从 log 前缀逐字节重建;⑤ runtime companion(`llm/stream` prepend 比对,失败 throw `InvariantError`)——**但默认生产 bundle 不装**(base/headless/web-app 三份 patch 0 命中),由 profile 自行挂载。
- 两处对 digest 原文的修正:architecture.md "a runtime invariant asserts it" 为真但有加载边界;one-shot 请求(compaction summarize 等)设计性排除在运行时不变量外(保证边界 = loop 请求)。
- 促成形态(草案):平台中立规则「凡往模型可见面注入内容的机制,必须同时产出一条可从中重建注入内容的持久记录;最强形态 = 请求构造即日志投影」。剩余门槛:对照实测 Claude Code——hook 注入 / skill 正文在 transcript 里是否可完整重建,列缺口。

### 候选 #2 核验:成立,够格当参考实现

- 结构 = `hook-protocol`(共享线协议库,非插件)+ `hooks-claude-code`(**7/30** CC 事件:SessionStart/UserPromptSubmit/PreToolUse/PostToolUse/Stop/SubagentStart/SubagentStop)+ `hooks-codex`(5 事件)。**Codex 侧是真实现**:975 行全链路测试(真 bash 子进程 + 真实 loop),代码量与 CC 侧同量级。
